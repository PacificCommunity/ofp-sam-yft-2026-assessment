\begin{frame}{Objectives in the stock assessment}
  \begin{itemize}
    \item Deliver report \textblue{on time}\\[2ex]
    \item Develop a model with \textblue{good convergence properties}\\[2ex]
    \item \textblue{Simplify} the model as much as possible\\[2ex]
    \item Incorporate \textblue{innovations} recommended by experts, including
    the SC\\[2ex]
    \item Check for and \textblue{remove errors}\\[2ex]
  \end{itemize}

\begin{frame}{Model overview}
  \begin{itemize}
    \item[] MULTIFAN-CL version 2.2.7.9\\[1.0ex]
    \item[] 5 regions\\[1.0ex]
    \item[] 1952--2024, quarterly time steps\\[1.0ex]
    \item[] 31 fisheries + 5 CPUE indices\\[1.0ex]
    \item[] Fixed M at terminal age, Lorenzen shape\\[1.0ex]
    \item[] Internally estimated growth, von Bertalanffy\\[1.0ex]
    \item[] Major reduction in parameters 1901 $\rightarrow$ 454 (was 11,688 in
    2020 assessment)\\[1.0ex]
    \item[] Regional scaling with multivariate normal prior\\[1.0ex]
    \item[] Likelihoods based on model fits to data\\[1.0ex]

      \fns - Length comps & \fns - CAAL (otoliths)\\
      \fns - CPUE         & \fns - Tags           \\

\begin{frame}{Main conclusions}\small
  \vspace{-1ex}
  \begin{itemize}
    \item Spawning depletion has been relatively stable since around 2005 to the
    present,\\
    between 0.35 and 0.50\\[1.5ex]
    \item All the ensemble models were above the
    $SB_\mathrm{current}/SB_{F=0}=0.20$ limit\\
    reference point and $F_\mathrm{current}<F_\mathrm{MSY}$
    \item Using a prior for $M$ in the ensemble analysis improved the
    incorporation of\\
    uncertainty about this key parameter in the assessment\\[1.5ex]
    \item Convergence problems remain in the model, likelihood conflict between
    the\\
    data sources\\[1.5ex]
    \item Slightly lower estimated relative stock size compared to previous
    assessment,\\
    primarily because of model settings related to tags\\[1.5ex]
    \item Orthogonal polynomial recruitment reduced the number of estimated\\
    parameters and improved model convergence\\[1.5ex]
    \item Effort creep incorporated in the assessment for the first
    time\\[1.5ex]
  \end{itemize}
\end{frame}
